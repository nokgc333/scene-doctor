# ADR-0004: (欠番)

## Status
Not used

## Context
ADR の番号が、0003 から 0005 に飛んでいる。git の履歴(全ブランチ)・README・仕様書・要件定義書に、ADR-0004 を作成・削除した痕跡も、参照も無い。理由は、記録から分からない。

## Decision
番号 0004 は、使われなかった番号として、このファイルで残す。意図した決定の記録が失われたわけではない(失われた記録を示す証拠が無い)。以降の ADR は、0008 から続ける(0005〜0007 は既存)。

## Consequences
ADR の連番に、説明のない欠番が無くなる。0004 を後から埋めるときは、このファイルを、その ADR で置き換える。
