# ADR-0003: 自動修正機能は見送り、リネーム候補の提示に留める

## Status
Accepted (2026-09-07)

## Context
命名規則違反やジオメトリ欠陥を「自動修正」まで行うことも技術的には可能だが、
特にジオメトリ修正（非多様体の自動解消等）は意図しない形状変化を招くリスクが高い。

## Decision
v1では「検出・レポート・リネーム候補の提示」に留め、リネーム以外の自動修正は行わない。
リネームについても`Apply Rename Candidates`ボタンでの明示的な確認（`hou.ui.displayConfirmation`）
を経てから実行する（SEC-003）。

## Consequences
良い: 誤った自動修正によるシーン破壊のリスクを避けられる
悪い: ジオメトリ欠陥自体の自動修正は今後の拡張課題として残る

## Alternatives Considered
- 非多様体エッジの自動マージ等の自動修正: 形状への影響が予測しづらく、
  ポートフォリオ段階での実装対象としてはリスクが高いため見送った
