# 大規模シーンでの計測

`python scripts/benchmark.py` で再現できる。偽の `hou` のオブジェクトで、検査ロジック(ジオメトリ・品質・ノード・命名)だけを測る。実 Houdini のジオメトリ取得の時間は含まない。

> 環境: macOS(Apple Silicon)/ Python 3.12 / 2026-10-28

| ノード数 | プリミティブ数 | 時間 (s) | ピークメモリ (MB) |
| --- | --- | --- | --- |
| 1,000 | 20,000 | 0.12 | 4 |
| 5,000 | 100,000 | 0.59 | 26 |
| 10,000 | 200,000 | 1.19 | 51 |

- 時間もメモリも、規模にほぼ比例する(2 乗では増えない)。
- 検査は、プリミティブとノードを 1 回ずつ走査する。重複した点の検出は、座標の丸めをキーにした辞書で、並べ替えを使わない。
